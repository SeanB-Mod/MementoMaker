MEMENTO MAKER 0.9.911 BETA
========================

Memento Maker is an unofficial Windows mod-creation tool for Two Point Museum.

Created by SeanB
Developed with assistance from ChatGPT by OpenAI
Special thanks to Beta Testers: Kiwiphant & Linelle Kardeen

BETA SOFTWARE
-------------
This is a beta release and may contain bugs. Back up important mod source artwork and report unexpected behaviour using Settings > Setup Paths & Maintenance > About & Diagnostics.

Memento Maker requires:
- Windows
- Microsoft .NET Framework 4.8
- Unity 2020.3.47f1
- The official Two Point Museum ModdingProject.zip SDK
- Steam running and logged in for Steam Workshop features

The installer does not install Unity or the Two Point Museum Modding SDK. Memento Maker's first-run setup will help locate them after installation.

Mod Status

Rebuilding

- Improved rebuild results with success and failure reporting for queued mods.
Workshop Reliability
